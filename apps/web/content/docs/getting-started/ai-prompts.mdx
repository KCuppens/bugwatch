Use these prompts with your favorite AI coding assistant to set up Bugwatch in minutes. Each prompt is self-contained — just paste it, provide your API key, and let the AI handle the integration.

For best results, include your API key directly in the prompt and mention your endpoint if you're self-hosting.

<Callout type="info">
AI tools that accept URL context can use `https://bugwatch.dev/llms-full.txt` for comprehensive Bugwatch documentation.
</Callout>

## Next.js (App Router)

```text
Add Bugwatch error tracking to my Next.js App Router project. Install @bugwatch/nextjs, create an instrumentation.ts file that calls init() with API key "YOUR_API_KEY", wrap the root layout with BugwatchProvider, and add the onRequestError hook in instrumentation.ts. Refer to https://bugwatch.dev/llms-full.txt for the full SDK docs.
```

**What the AI will do:**
- Install `@bugwatch/nextjs`
- Create `instrumentation.ts` with `init({ apiKey })`
- Add `BugwatchProvider` to `app/layout.tsx`
- Configure `onRequestError` for server-side error capture

## MCP Server Setup

For AI coding tools (Claude Desktop, Cursor, Windsurf), install the Bugwatch MCP server:

```json
{
  "mcpServers": {
    "bugwatch": {
      "command": "npx",
      "args": ["@bugwatch/mcp"],
      "env": {
        "BUGWATCH_API_KEY": "bw_agent_...",
        "BUGWATCH_URL": "https://api.bugwatch.dev"
      }
    }
  }
}
```

This enables your AI assistant to search issues, resolve errors, create monitors, and more directly from your editor.

See the [Agent Integration docs](/docs/agents/mcp) for full details.

## Tips

- **Include your API key** directly in the prompt so the AI can write working code immediately
- **Specify your endpoint** if self-hosting: add `endpoint: "https://your-domain.com/api/v1"` to prompts
- **Reference the docs URL** — AI tools that support URL context can read `https://bugwatch.dev/llms-full.txt` for complete, up-to-date documentation
- **Be specific** about your framework version and project structure for more accurate results
