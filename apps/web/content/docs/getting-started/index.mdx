# Getting Started with Bugwatch

This guide walks you through the full setup process. By the end, you will have Bugwatch capturing real errors from your application.

## Prerequisites

- A [Bugwatch account](https://bugwatch.dev/signup) (free tier available) or a [self-hosted instance](/docs/self-hosting)
- An application you want to monitor (any language or framework with a supported SDK)

<Callout type="info">
New to error tracking? Start with the [Create a Project](/docs/getting-started/create-project) guide, then install an SDK for your framework. You'll be capturing errors in under 5 minutes.
</Callout>

## Step 1: Sign Up

Head to [bugwatch.dev/signup](https://bugwatch.dev/signup) and create your account. You can sign up with an email address and password. After signing up, you will land on the onboarding wizard that guides you through the remaining steps.

If you are self-hosting, navigate to your instance's URL and create the initial admin account.

## Step 2: Create a Project

A **project** maps to one deployable unit -- typically a single application or service. Each project gets its own API key and isolated error stream.

1. From the dashboard, click **New Project**
2. Give it a descriptive name (e.g., `web-app`, `api-server`, `billing-service`)
3. Copy the generated API key (it looks like `bw_live_xxxxx`)

For a detailed walkthrough, see [Create a Project](/docs/getting-started/create-project).

## Step 3: Install an SDK

Choose the SDK that matches your stack and install it via your package manager.

### JavaScript

```bash
# Next.js / React / Node.js
npm install @bugwatch/nextjs
```

```js
// Initialize in your app entry point
import { init } from "@bugwatch/nextjs";

init({
  apiKey: "bw_live_xxxxx",
});
```

### Python

```bash
pip install bugwatch
```

```python
import bugwatch

bugwatch.init(api_key="bw_live_xxxxx")
```

### Rust

```toml
# Cargo.toml
[dependencies]
bugwatch = "0.1"
```

```rust
fn main() {
    bugwatch::init("bw_live_xxxxx");
}
```

See the full [SDK documentation](/docs/sdks) for framework-specific guides including Django, Flask, FastAPI, Express, and Fastify.

## Step 4: Verify Your Integration

Trigger a test error to confirm data flows from your application to the Bugwatch dashboard.

```js
// JavaScript example
throw new Error("Bugwatch test error");
```

```python
# Python example
raise Exception("Bugwatch test error")
```

Within seconds, the error should appear on your [dashboard](/dashboard). If it does not, check the [troubleshooting section](/docs/getting-started/verify-integration#troubleshooting).

For the full verification walkthrough, see [Verify Integration](/docs/getting-started/verify-integration).

## Next Steps

Once your integration is confirmed:

- **Set up alerting** -- get notified on [Slack, email, or webhooks](/docs/alerting) when new errors occur
- **Install the server agent** -- monitor [host-level metrics](/docs/server-agent) alongside your errors
- **Explore the API** -- automate workflows with the [REST API](/docs/api-reference)
- **Invite your team** -- add team members from the project settings page
