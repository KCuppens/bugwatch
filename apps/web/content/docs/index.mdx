# Welcome to Bugwatch

Bugwatch is an open-source error tracking platform built for modern development teams. It captures, aggregates, and helps you resolve errors across your entire stack -- so bugs never slip through the cracks.

## Quick Start

Get up and running in under five minutes:

1. [Sign up](https://bugwatch.dev/signup) for a free account (or [self-host](/docs/self-hosting))
2. [Create a project](/docs/getting-started/create-project) and grab your API key
3. [Install an SDK](/docs/sdks) for your framework
4. [Verify your integration](/docs/getting-started/verify-integration) by sending a test error
