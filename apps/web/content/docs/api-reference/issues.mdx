# Issues

Issues represent grouped error events that share the same fingerprint. Each unique error type and stack trace combination is grouped into a single issue with an event count, affected user count, and status.

## GET /projects/:project_id/issues

List issues for a project with optional filtering.

**Authentication:** Bearer token required

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| `project_id` | string | Project ID |

### Query Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| `page` | integer | `1` | Page number |
| `per_page` | integer | `20` | Items per page (max 100) |
| `status` | string | - | Filter by status: `unresolved`, `resolved`, `ignored` |
| `level` | string | - | Filter by level: `fatal`, `error`, `warning`, `info`, `debug` |
| `environment` | string | - | Filter by environment (e.g., `production`, `staging`) |

### Example

```bash
curl "https://api.bugwatch.dev/api/v1/projects/proj_abc123/issues?status=unresolved&level=error&page=1&per_page=25" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

### Response `200 OK`

```json
{
  "data": [
    {
      "id": "iss_def456",
      "project_id": "proj_abc123",
      "fingerprint": "a1b2c3d4e5f6",
      "title": "TypeError: Cannot read properties of undefined (reading 'map')",
      "status": "unresolved",
      "level": "error",
      "first_seen": "2025-01-15T14:22:00Z",
      "last_seen": "2025-01-16T09:15:00Z",
      "count": 47,
      "user_count": 12,
      "environment": "production"
    }
  ],
  "pagination": {
    "page": 1,
    "per_page": 25,
    "total": 142,
    "total_pages": 6
  }
}
```

## POST /projects/:project_id/issues/_search

Advanced search with multiple filters, sorting, and facet counts. The search endpoint uses `_search` as a path suffix.

**Authentication:** Bearer token required

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| `project_id` | string | Project ID |

### Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `filters` | object | No | Search filters (see below) |
| `sort` | object | No | Sort configuration |
| `page` | integer | No | Page number (default: 1) |
| `per_page` | integer | No | Items per page (default: 50, max: 100) |

### Filter Fields

| Field | Type | Description |
|---|---|---|
| `status` | string[] | Filter by statuses (e.g., `["unresolved", "resolved"]`) |
| `level` | string[] | Filter by levels (e.g., `["error", "fatal"]`) |
| `environment` | string[] | Filter by environments |
| `text` | string | Full-text search in issue title (max 200 characters) |
| `count_gt` | integer | Issues with event count greater than |
| `count_lt` | integer | Issues with event count less than |
| `count_gte` | integer | Issues with event count greater than or equal to |
| `count_lte` | integer | Issues with event count less than or equal to |
| `users_gt` | integer | Issues affecting more than N users |
| `users_lt` | integer | Issues affecting fewer than N users |
| `first_seen_after` | string | ISO 8601 date: issues first seen after |
| `first_seen_before` | string | ISO 8601 date: issues first seen before |
| `last_seen_after` | string | ISO 8601 date: issues last seen after |
| `last_seen_before` | string | ISO 8601 date: issues last seen before |

### Sort Configuration

| Field | Type | Description |
|---|---|---|
| `field` | string | Field to sort by: `last_seen`, `first_seen`, `count`, `user_count`, `level` |
| `direction` | string | Sort direction: `asc` or `desc` |

### Example

```bash
curl -X POST https://api.bugwatch.dev/api/v1/projects/proj_abc123/issues/_search \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "filters": {
      "status": ["unresolved"],
      "level": ["error", "fatal"],
      "text": "TypeError",
      "count_gte": 10
    },
    "sort": {
      "field": "last_seen",
      "direction": "desc"
    },
    "page": 1,
    "per_page": 25
  }'
```

### Response `200 OK`

```json
{
  "data": [ ... ],
  "pagination": {
    "page": 1,
    "per_page": 25,
    "total": 18,
    "total_pages": 1
  },
  "facets": {
    "status": { "unresolved": 18, "resolved": 5, "ignored": 2 },
    "level": { "error": 15, "fatal": 3, "warning": 7 },
    "environment": { "production": 20, "staging": 5 }
  },
  "query_time_ms": 12
}
```

The `facets` object provides counts across all issues in the project (unfiltered), useful for building filter UIs.

## PATCH /projects/:project_id/issues/:issue_id

Update an issue's status.

**Authentication:** Bearer token required

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| `project_id` | string | Project ID |
| `issue_id` | string | Issue ID |

### Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `status` | string | No | New status: `unresolved`, `resolved`, or `ignored` |

### Example

```bash
curl -X PATCH https://api.bugwatch.dev/api/v1/projects/proj_abc123/issues/iss_def456 \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "resolved"
  }'
```

### Response `200 OK`

```json
{
  "data": {
    "id": "iss_def456",
    "project_id": "proj_abc123",
    "fingerprint": "a1b2c3d4e5f6",
    "title": "TypeError: Cannot read properties of undefined (reading 'map')",
    "status": "resolved",
    "level": "error",
    "first_seen": "2025-01-15T14:22:00Z",
    "last_seen": "2025-01-16T09:15:00Z",
    "count": 47,
    "user_count": 12,
    "environment": "production"
  }
}
```

### Errors

| Status | Description |
|---|---|
| `400` | Invalid status value |
| `403` | You do not own this project |
| `404` | Issue or project not found |

## GET /projects/:project_id/issues/:issue_id/impact

Get impact metrics for an issue, including affected users, browser/OS distribution, and trend data.

**Authentication:** Bearer token required

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| `project_id` | string | Project ID |
| `issue_id` | string | Issue ID |

### Example

```bash
curl https://api.bugwatch.dev/api/v1/projects/proj_abc123/issues/iss_def456/impact \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

### Response `200 OK`

```json
{
  "data": {
    "unique_users": 12,
    "unique_sessions": 18,
    "total_events": 47,
    "first_seen": "2025-01-15T14:22:00Z",
    "last_seen": "2025-01-16T09:15:00Z",
    "last_hour_count": 5,
    "trend_percent": 25,
    "is_trending": false,
    "browsers": [
      { "name": "Chrome 120", "count": 30, "percentage": 64 },
      { "name": "Firefox 121", "count": 10, "percentage": 21 },
      { "name": "Safari 17", "count": 7, "percentage": 15 }
    ],
    "operating_systems": [
      { "name": "macOS", "count": 25, "percentage": 53 },
      { "name": "Windows", "count": 15, "percentage": 32 },
      { "name": "Linux", "count": 7, "percentage": 15 }
    ]
  }
}
```

The `trend_percent` indicates the change in event frequency compared to the previous hour. `is_trending` is `true` when `trend_percent > 50` and `last_hour_count > 5`.
