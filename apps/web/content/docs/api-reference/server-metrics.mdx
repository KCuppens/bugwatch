# Server Metrics

Server metrics endpoints allow you to push system metrics from your servers using the Bugwatch agent and query historical data from the dashboard. Server monitoring requires a **Pro tier or higher**.

## POST /metrics

Ingest server metrics from the Bugwatch agent. This endpoint is called periodically by the agent running on your servers.

**Authentication:** Project API key via `Authorization: Bearer YOUR_API_KEY` or `X-API-Key: YOUR_API_KEY`
**Tier:** Pro or higher
**Rate Limits:** Subject to your plan's rate limit

### Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `server_id` | string | Yes | Unique server identifier (agent-generated) |
| `hostname` | string | Yes | Server hostname |
| `os` | string | No | Operating system (e.g., `Ubuntu 22.04`) |
| `kernel` | string | No | Kernel version |
| `cpu` | object | No | CPU metrics |
| `memory` | object | No | Memory metrics |
| `swap` | object | No | Swap metrics |
| `network` | object | No | Network metrics |
| `load` | object | No | System load averages |
| `uptime_seconds` | integer | No | Server uptime in seconds |
| `disks` | array | No | Disk usage per mount point |
| `processes` | array | No | Top processes by resource usage |
| `docker` | array | No | Docker container status |

### CPU Object

| Field | Type | Description |
|---|---|---|
| `usage_percent` | float | CPU usage percentage (0-100) |

### Memory Object

| Field | Type | Description |
|---|---|---|
| `total_bytes` | integer | Total memory in bytes |
| `used_bytes` | integer | Used memory in bytes |
| `available_bytes` | integer | Available memory in bytes |
| `usage_percent` | float | Memory usage percentage (0-100) |

### Swap Object

| Field | Type | Description |
|---|---|---|
| `total_bytes` | integer | Total swap in bytes |
| `used_bytes` | integer | Used swap in bytes |

### Network Object

| Field | Type | Description |
|---|---|---|
| `rx_bytes_per_sec` | integer | Incoming bytes per second |
| `tx_bytes_per_sec` | integer | Outgoing bytes per second |

### Load Object

| Field | Type | Description |
|---|---|---|
| `avg_1` | float | 1-minute load average |
| `avg_5` | float | 5-minute load average |
| `avg_15` | float | 15-minute load average |

### Disk Object (array item)

| Field | Type | Description |
|---|---|---|
| `mount` | string | Mount point path |
| `filesystem` | string | Filesystem type |
| `total_bytes` | integer | Total disk space |
| `used_bytes` | integer | Used disk space |
| `available_bytes` | integer | Available disk space |
| `usage_percent` | float | Disk usage percentage |

### Process Object (array item)

| Field | Type | Description |
|---|---|---|
| `pid` | integer | Process ID |
| `name` | string | Process name |
| `cpu_percent` | float | CPU usage percentage |
| `mem_percent` | float | Memory usage percentage |
| `user` | string | Process owner |

### Docker Container Object (array item)

| Field | Type | Description |
|---|---|---|
| `name` | string | Container name |
| `id` | string | Container ID |
| `status` | string | Container status (e.g., `running`, `stopped`) |
| `cpu_percent` | float | CPU usage percentage |
| `mem_usage` | string | Memory usage string (e.g., `256MiB / 4GiB`) |
| `mem_percent` | float | Memory usage percentage |

### Example

```bash
curl -X POST https://api.bugwatch.dev/api/v1/metrics \
  -H "Authorization: Bearer YOUR_PROJECT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "server_id": "srv-prod-01",
    "hostname": "prod-web-1.example.com",
    "os": "Ubuntu 22.04.3 LTS",
    "kernel": "5.15.0-91-generic",
    "cpu": {
      "usage_percent": 42.5
    },
    "memory": {
      "total_bytes": 17179869184,

      "available_bytes": 8589934592,

      "total_bytes": 4294967296,

    },
    "network": {
      "rx_bytes_per_sec": 125000,
      "tx_bytes_per_sec": 80000
    },
    "load": {
      "avg_1": 1.2,
      "avg_5": 0.8,
      "avg_15": 0.6
    },
    "uptime_seconds": 2592000,
    "disks": [
      {
        "mount": "/",
        "filesystem": "ext4",
        "total_bytes": 107374182400,
        "used_bytes": 42949672960,
        "available_bytes": 64424509440,
        "usage_percent": 40.0
      }
    ],
    "processes": [
      {
        "pid": 1234,
        "name": "node",

```

### Response `202 Accepted`

```json
{
  "status": "accepted",
  "server_db_id": "srv_db_abc123"
}
```

### Errors

| Status | Description |
|---|---|
| `401` | Missing or invalid API key |
| `402` | Server monitoring requires Pro plan or higher |
| `429` | Rate limit exceeded |

## GET /projects/:project_id/servers

List all servers that have reported metrics for a project.

**Authentication:** Bearer token required

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| `project_id` | string | Project ID |

### Example

```bash
curl https://api.bugwatch.dev/api/v1/projects/proj_abc123/servers \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

### Response `200 OK`

```json
{
  "data": [
    {
      "id": "srv_db_abc123",
      "project_id": "proj_abc123",
      "server_id": "srv-prod-01",
      "hostname": "prod-web-1.example.com",
      "os": "Ubuntu 22.04.3 LTS",
      "kernel": "5.15.0-91-generic",
      "last_seen_at": "2025-01-16T09:15:00Z",
      "created_at": "2025-01-01T00:00:00Z"
    }
  ]
}
```

## GET /projects/:project_id/servers/status

Check whether any server agents have reported to the project. Useful during onboarding.

**Authentication:** Bearer token required

### Example

```bash
curl https://api.bugwatch.dev/api/v1/projects/proj_abc123/servers/status \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

### Response `200 OK`

```json
{
  "has_agent": true,
  "server_count": 2
}
```

## GET /projects/:project_id/servers/:server_id/metrics

Get time series metrics for a server over a specified period.

**Authentication:** Bearer token required

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| `project_id` | string | Project ID |
| `server_id` | string | Server database ID |

### Query Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| `period` | string | `1h` | Time period: `1h`, `6h`, `24h`, or `7d` |

### Example

```bash
curl "https://api.bugwatch.dev/api/v1/projects/proj_abc123/servers/srv_db_abc123/metrics?period=24h" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

## GET /projects/:project_id/servers/:server_id/metrics/latest

Get the most recent metrics snapshot for a server.

**Authentication:** Bearer token required

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| `project_id` | string | Project ID |
| `server_id` | string | Server database ID |

### Example

```bash
curl https://api.bugwatch.dev/api/v1/projects/proj_abc123/servers/srv_db_abc123/metrics/latest \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

### Response `200 OK`

```json
{
  "data": {
    "id": "met_001",
    "recorded_at": "2025-01-16T09:15:00Z",
    "cpu_usage_percent": 42.5,
    "load_avg_1": 1.2,
    "load_avg_5": 0.8,
    "load_avg_15": 0.6,
    "mem_total_bytes": 17179869184,
    "mem_used_bytes": 8589934592,
    "mem_available_bytes": 8589934592,
    "mem_usage_percent": 50.0,
    "swap_total_bytes": 4294967296,
    "swap_used_bytes": 0,
    "net_rx_bytes_per_sec": 125000,
    "net_tx_bytes_per_sec": 80000,
    "uptime_seconds": 2592000,
    "disks": [ ... ],
    "processes": [ ... ],
    "docker": [ ... ]
  },
  "server": {
    "id": "srv_db_abc123",
    "project_id": "proj_abc123",
    "server_id": "srv-prod-01",
    "hostname": "prod-web-1.example.com",
    "os": "Ubuntu 22.04.3 LTS",
    "kernel": "5.15.0-91-generic"
  }
}
```

If no metrics have been reported yet, `data` will be `null` and the `server` object will still be returned.
