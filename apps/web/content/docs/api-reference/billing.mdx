# Billing

The billing endpoints manage organizations, team members, Stripe subscriptions, invoices, payment methods, and usage tracking. All billing endpoints require Bearer token authentication.

## Organizations

### GET /organization

Get the current user's organization.

**Authentication:** Bearer token required

### Example

```bash
curl https://api.bugwatch.dev/api/v1/organization \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

### Response `200 OK`

```json
{
  "organization": {
    "id": "org_xyz789",
    "name": "Acme Corp",
    "slug": "acme-corp-a1b2c3d4",
    "owner_id": "usr_abc123",
    "tier": "pro",
    "seats": 5,
    "subscription_status": "active",
    "billing_interval": "monthly",
    "current_period_start": "2025-01-01T00:00:00Z",
    "current_period_end": "2025-02-01T00:00:00Z",
    "cancel_at_period_end": false,
    "stripe_customer_id": "cus_xxx",
    "stripe_subscription_id": "sub_xxx"
  },
  "members_count": 3,
  "is_owner": true
}
```

---

### POST /organization

Create a new organization. Each user can only have one organization.

**Authentication:** Bearer token required

### Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `name` | string | Yes | Organization name |

### Example

```bash
curl -X POST https://api.bugwatch.dev/api/v1/organization \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Acme Corp"
  }'
```

### Response `200 OK`

Returns the organization response with `members_count: 1` and `is_owner: true`.

### Errors

| Status | Description |
|---|---|
| `409` | User already has an organization |

---

### PATCH /organization

**Authentication:** Bearer token required (owner only)

### Request Body

| Field | Type | Required | Description |

```bash
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{

  }'
```

### POST /organization/members

Add a member to the organization by email. Only owners and admins can add members. The user must already have a Bugwatch account.

**Authentication:** Bearer token required (owner or admin)

### Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `email` | string | Yes | Email of the user to add |
| `role` | string | No | Role: `admin` or `member` (default: `member`) |

### Example

```bash
curl -X POST https://api.bugwatch.dev/api/v1/organization/members \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "new-dev@example.com",
    "role": "member"
  }'
```

### Errors

| Status | Description |
|---|---|
| `402` | Seat limit reached |
| `403` | Only owner or admin can add members |
| `404` | User not found |
| `409` | User is already a member |

---

### DELETE /organization/members/:member_user_id

### POST /billing/checkout

Create a Stripe checkout session for a new subscription or upgrade.

**Authentication:** Bearer token required

### Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `tier` | string | Yes | Plan tier: `pro` or `team` |
| `seats` | integer | No | Number of seats (default: 1) |
| `annual` | boolean | No | Annual billing (default: false) |
| `success_url` | string | Yes | URL to redirect after successful payment |
| `cancel_url` | string | Yes | URL to redirect if payment is canceled |

### Example

```bash
curl -X POST https://api.bugwatch.dev/api/v1/billing/checkout \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "tier": "pro",
    "seats": 3,
    "annual": false,
    "success_url": "https://app.bugwatch.dev/dashboard/settings?checkout=success",
    "cancel_url": "https://app.bugwatch.dev/dashboard/settings?checkout=canceled"
  }'
```

### Response `200 OK`

```json
{
  "checkout_url": "https://checkout.stripe.com/c/pay/cs_xxx..."
}
```

Redirect the user to `checkout_url` to complete the payment.


### POST /billing/change-plan

Change the subscription plan (upgrade or downgrade).

**Authentication:** Bearer token required (owner only)

### Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `tier` | string | Yes | New plan tier: `pro` or `team` |
| `seats` | integer | No | Number of seats (default: current seats) |
| `annual` | boolean | No | Annual billing (default: current interval) |

### Example

```bash
curl -X POST https://api.bugwatch.dev/api/v1/billing/change-plan \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "tier": "team",
    "seats": 10,
    "annual": true
  }'
```

### Response `200 OK`

```json
{
  "success": true,
  "tier": "team",
  "seats": 10,
  "message": "Plan updated successfully"
}
```

---

## Dashboard

### GET /billing/dashboard

Get a summary of the billing state, including cost, seats, and period information.

**Authentication:** Bearer token required

### Example

```bash
curl https://api.bugwatch.dev/api/v1/billing/dashboard \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

### Response `200 OK`

```json
{
  "current_tier": "pro",
  "monthly_cost_cents": 3600,
  "seats_used": 3,
  "seats_total": 5,
  "billing_period_start": "2025-01-01T00:00:00Z",
  "billing_period_end": "2025-02-01T00:00:00Z",
  "is_past_due": false,
  "cancel_at_period_end": false
}
```

The `monthly_cost_cents` is calculated as: Pro = $12/seat/month, Team = $21/seat/month, Free = $0.
